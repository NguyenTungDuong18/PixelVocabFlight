## Đọc theo thứ tự

**Kịch bản chi tiết nằm trong Obsidian vault của người dùng, ngoài repo:** `C:\Users\Admin\Documents\Obsidian Vault\story\`. Khi đọc hay sửa kịch bản thì làm ở đó. Từ đây gọi tắt là `<vault>/story/`.

Mọi file nằm chung trong `<vault>/story/` (không có thư mục con), liên kết với nhau bằng `[[...]]` của Obsidian. Tên file theo dạng `Hồi N - Chương N - Tên.md`. Mỗi hồi có một file `Hồi N - Giới thiệu - <tên hồi>.md` chứa câu hỏi của hồi, danh sách chương và màn tổng kết lặng; đọc file đó trước.
